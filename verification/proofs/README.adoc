= Cross-Project Formal Proofs

This directory hosts *cross-project* formal proofs only — proofs that import
or relate **two or more** constituent repos of the type-theory pipeline.

[IMPORTANT]
====
`nextgen-typing` is a coordination repo. *Single-project* proofs do **not**
belong here — they belong in the repo that owns the subject matter:

* TypeLL kernel proofs (dependent/linear/session types, QTT) → `typell`
* WasmGC memory-safety / ABI / FFI / memory-layout proofs → `typed-wasm`
* The echo-types library's own proofs (Echo/EchoLinear/EchoResidue) → `echo-types`
* Research prototype proofs → `kategoria`

The authoritative routing table is
`.machine_readable/bot_directives/placement.a2ml`, and CI enforces this
boundary via `.github/workflows/coordination-boundary.yml`
(`scripts/check-coordination-boundary.sh`).
====

== Current contents

[source]
----
proofs/
└── agda/
    ├── EchoTyping.agda          # echo-types <-> AffineScript/typed-wasm pipeline
    ├── Verification.agda        # aggregator: `agda Verification.agda` checks the set
    └── nextgen-typing.agda-lib  # depends on: standard-library, echo-types
----

`EchoTyping.agda` is the worked example of a qualifying proof: it depends on the
`hyperpolymath/echo-types` Agda library and proves that the pipeline's
information-losing typing operations (AffineScript affine weakening; refinement
erasure into the typed-wasm/kernel layer) are instances of echo-types' fiber
construction. It genuinely spans `echo-types`, `affinescript`, and `typed-wasm`,
so it is coordination material rather than any one project's.

== Adding a proof here

Before adding anything, check the gate:

. *Does it import or relate two or more constituent repos?* If not, it is a
  single-project proof — put it in the owning repo (see `placement.a2ml`).
. If it qualifies, add the file under the appropriate prover subdirectory, then
  register it in **both**:
  * `[verification].allowed-proofs` in `.machine_readable/bot_directives/placement.a2ml`, and
  * `ALLOWED_PROOFS` in `scripts/check-coordination-boundary.sh`.
. Ensure `--safe` / `%default total` / no escape hatches (see Banned Patterns).
. Run the gate. `just proof-enrolment` fails when a proof source under
  `verification/proofs/` is not registered in *both* places above, when a
  registered entry has no file behind it, when the two registries disagree,
  and when zero proofs are enrolled. It is the first dependency of
  `just proof-check-all`, so an unlisted proof cannot reach `main` green.

== How a proof is checked

Every proof source here is typechecked by the real all-proofs target, which CI
runs on any change to proofs, registries, `Justfile` or the lane:

[source,bash]
----
just proof-check-all        # .github/workflows/proof-ci.yml
----

A prover that is required (because proofs for it are enrolled) but absent from
`PATH` makes the run **BLOCKED** (exit 2) — the lane never skips it and never
turns that into a pass. A prover with no enrolled sources prints `NONE`, not
`PASS`.

The Agda layer needs its library manifest activated, otherwise Agda reports
`[ModuleNameDoesntMatchFileName]` for every module (observed on 2026-11-01):

[source,bash]
----
agda --safe --library=nextgen-typing verification/proofs/agda/Verification.agda
----

`nextgen-typing.agda-lib`, `standard-library`, `echo-types` and its own
dependency `absolute-zero` must be registered in `<agda-app-dir>/libraries`
(`agda --print-agda-app-dir`). `.github/workflows/proof-ci.yml` pins all four.

== Banned patterns

The following MUST NOT appear in any proof file:

* `believe_me`, `assert_total` (Idris2)
* `postulate` (Idris2/Agda)
* `sorry` (Lean4)
* `Admitted` (Coq)
* `unsafeCoerce` (Haskell)
* `Obj.magic` (OCaml/ReScript)

CI enforces this with `just proof-scan-dangerous`
(`scripts/proof-scan-dangerous.sh`), which runs inside `just proof-check-all`.
It is comment-aware — a prose mention such as "zero postulates" is not flagged,
while a real escape hatch is, including inside `{- ... -}` blocks. A scan that
finds no proof files to scan fails rather than reporting clean.
