== Tech Stack

* **Coordination & documentation**: AsciiDoc (`.adoc`), Markdown, A2ML (`.a2ml`), Nickel/K9 (`.k9`, `.k9.ncl`), Graphviz (`.dot` → `.svg`).
* **Cross-project formal verification (`verification/proofs/`)**: Agda (`--safe --without-K`) source-of-truth proofs, independently rechecked in Rocq (Coq 8.18) and core Lean 4 (4.15.0, zero Mathlib).
* **Gate scripts**: Bash 5 + `jq` + `git` (`scripts/` and `tests/`).

== Set Up Development Environment

[source,bash]
----
git clone https://github.com/hyperpolymath/nextgen-typing.git
cd nextgen-typing
----

For a reproducible Guix shell when Guix is available:

[source,bash]
----
guix shell -D -f build/guix.scm
----

For coordinator boundary, drift, and ledger checks, Bash, `jq`, and Git are sufficient; Agda, Coq (`coqc`/`coqchk`), and Lean 4 (`lean`) are required when compiling proof witnesses locally.

== Validate and Test

[source,bash]
----
./scripts/check-coordination-boundary.sh
./scripts/check-pipeline-drift.sh .
./scripts/check-proof-enrolment.sh
./scripts/check-proof-ledger.sh
./scripts/proof-scan-dangerous.sh
bash tests/proofs/run-ledger-controls.sh
bash tests/rsr_antipattern_heading_test.sh
----

With `just` and the proof kernels installed:

[source,bash]
----
just validate
just validate-coordination
just validate-pipeline-drift
just proof-check-all
----

== Key Invariants

* **No compiler or single-project code**: `nextgen-typing` hosts only cross-project coordination artefacts and explicitly enrolled cross-project proofs (`scripts/check-coordination-boundary.sh` and `.machine_readable/bot_directives/placement.a2ml`).
* **Synchronized pipeline metadata**: `STATE.a2ml`, `META.a2ml`, `ECOSYSTEM.a2ml`, `docs/PIPELINE.adoc`, and `docs/ARCHITECTURE.adoc` must remain synchronized (`scripts/check-pipeline-drift.sh`).
* **Zero proof escape hatches**: every enrolled proof must pass `PROOF-POLICY` kernel assumption checks (`coqchk` + `Print Assumptions`, `#print axioms` + `getModuleIdxFor?`, and `agda --safe --without-K`) with zero unwaived axioms (`scripts/check-proof-ledger.sh`).
