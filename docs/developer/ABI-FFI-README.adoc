= ABI/FFI — not defined in this repo

`nextgen-typing` is a *coordination and cross-project verification repo*: it
documents and connects the type-theory pipeline, hosts cross-project formal
proofs under `verification/proofs/`, and holds no compiler or application code,
so it defines no ABI and no FFI of its own.

NOTE: the previous RSR-template scaffold describing an Idris2 ABI and Zig FFI
directory tree was removed under OQ-001 (PR #56) because this repository does
not host single-project ABI/FFI implementations.

== Where the ABI and proofs actually live

* Cross-project formal verification witnesses: `verification/proofs/`
  (tracked in `verification/proofs/LEDGER.json` and `PROOF-STATUS.adoc`)
* WasmGC memory-safety proofs + convergence ABI: `hyperpolymath/typed-wasm`
* Aggregate-library conventions (ADR-004): `hyperpolymath/typed-wasm`

For where any given artefact belongs, see the authoritative routing table at
`.machine_readable/bot_directives/placement.a2ml` and the summary in `AGENTS.md`.
