= Quickstart
:toc: preamble

Clone and run the `nextgen-typing` coordination and proof-ledger checks in 60 seconds.

== Prerequisites

* Git 2.40+
* Bash 5+ and `jq`
* `just` (optional command runner)
* Agda, Coq (`coqc`/`coqchk`), and Lean 4 (only when compiling proof witnesses locally)

== Clone and Verify

[source,bash]
----
git clone https://github.com/hyperpolymath/nextgen-typing.git
cd nextgen-typing
./scripts/check-coordination-boundary.sh
./scripts/check-pipeline-drift.sh .
./scripts/check-proof-enrolment.sh
./scripts/check-proof-ledger.sh
----
