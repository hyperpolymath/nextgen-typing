= AI Guidance Directory

Put AI-facing instructions in this folder (with root pointers limited to `AGENTS.md` and `CLAUDE.md`).

Files in this directory:

* `AI.a2ml` — structured agent directives
* `.clinerules`, `.cursorrules`, `.windsurfrules` — editor rules
* `PLACEHOLDERS.adoc` — RSR template placeholder reference

Avoid scattering agent session files around the repo root.

Recommended machine read order:

* `.machine_readable/descriptiles/anchor/ANCHOR.a2ml`
* `.machine_readable/policies/MAINTENANCE-AXES.a2ml`
* `.machine_readable/policies/MAINTENANCE-CHECKLIST.a2ml`
* `.machine_readable/policies/SOFTWARE-DEVELOPMENT-APPROACH.a2ml`
* `.machine_readable/descriptiles/STATE.a2ml`
* `.machine_readable/descriptiles/META.a2ml`
