== What this repository is

`nextgen-typing` is the coordination monorepo and cross-project verification host for the hyperpolymath type-theory pipeline (`katagoria → typell → typed-wasm → PanLL`) and its six research families (`echo-types`, `epistemic-types`, `tropical-types`, `residual-evidence-types`, `choreographic-types`, `secret-types`). It is not a compiler, runtime service, or single-project package.

== Find a project or specification

2. Open link:docs/ARCHITECTURE.adoc[docs/ARCHITECTURE.adoc] and link:docs/PIPELINE.adoc[docs/PIPELINE.adoc] for the architectural contracts and machine-readable pipeline graph.
3. Open link:docs/TYPE-CONNECTIONS.adoc[docs/TYPE-CONNECTIONS.adoc] for the shared six-family map, glossary, and inter-family bridge obligations.
4. Check link:PROOF-STATUS.adoc[PROOF-STATUS.adoc] and `verification/proofs/LEDGER.json` for cross-project verification status (`XP-1`, Grade `2i` across Agda, Rocq, and Lean 4).

== Installation

There is no runtime binary or service to install from this repository. To build or install a language, kernel, or target toolchain, follow the instructions in its owning repository (`typell`, `typed-wasm`, `affinescript`, `ephapax`, `echo-types`, `residual-evidence-types`, etc.).
