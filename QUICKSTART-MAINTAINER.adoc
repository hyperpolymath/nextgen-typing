= nextgen-typing — Coordinator Maintenance Guide
:toc:
:toclevels: 2

== Scope

`nextgen-typing` is a pure coordination and cross-project verification repository; it produces no runtime service, compiler binary, container deployment, or installable package. Constituent repositories (`typell`, `typed-wasm`, `echo-types`, `epistemic-types`, `tropical-types`, `residual-evidence-types`, `choreographic-types`, `secret-types`) own their own build, release, and packaging pipelines.

== Dependencies and Checks

* **Coordinator & ledger gates**: Bash 5+, `jq`, `git`, `just` (optional runner), Graphviz (`dot` for `just type-map`).
* **Cross-project proof CI (`Proof CI`)**: Agda 2.8.0 (`agda-stdlib` v2.3 + pinned `hyperpolymath/echo-types`), Coq 8.18.0 (`coqc`, `coqchk`, `coqtop`), and core Lean 4.15.0 (SHA-256-verified Linux release tarball).

[source,bash]
----
./scripts/check-coordination-boundary.sh
./scripts/check-pipeline-drift.sh .
just validate
just proof-check-all
git diff --check
----

== Maintaining Synchronized Surfaces

1. **Pipeline state**: when updating `.machine_readable/descriptiles/STATE.a2ml`, keep `last-updated` synchronized across `STATE.a2ml`, `META.a2ml`, `ECOSYSTEM.a2ml`, `docs/PIPELINE.adoc` (`version`), and `docs/ARCHITECTURE.adoc` (header date), then run `./scripts/check-pipeline-drift.sh .`.
2. **Cross-project proofs**: every proof file under `verification/proofs/` must be enrolled in both `scripts/check-coordination-boundary.sh` (`ALLOWED_PROOFS`), `.machine_readable/bot_directives/placement.a2ml` (`[verification].allowed-proofs`), the prover's `MANIFEST`, and `verification/proofs/LEDGER.json`.
3. **Workflows**: `.github/workflows/actions.lock` locks every GitHub Action dependency; run `gh actions-lock` whenever workflow `uses:` references change.
